- **On an iPad, Settings > Tools stopped telling you about your iPhone** (IMPROVE-10). Six of the tool descriptions named the device in the sentence itself: the voice tool spoke with "the voices already on your iPhone", the vibrate tool "makes this iPhone buzz", the picture tool named "your iPhone itself". An iPad reaches Settings as a sidebar row, so all six were read there and all six were wrong. The rows no longer name the device at all, because the text they come from cannot know which device it is running on, and the one sentence that can - the footer under the whole section - now says it properly: everything runs on this iPhone, or this iPad, or this Mac. In five of the six the device name was saying nothing the same sentence did not already say, since each one ends in "Works offline" or "Nothing leaves the device", so every row came out shorter rather than vaguer. The guard that polices these lines used to ban one particular phrase and now asks for the promise instead: a row may not claim to know which device you are holding.

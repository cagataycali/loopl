- **The Hugging Face section in Settings stopped being "missing" on an iPad** (IMPROVE-9). The test that proves you can reach it walks down Settings a screen at a time and stops when the list stops producing anything new — except it decided that by comparing **one element**, the last row it could see. On an iPad a Settings section footer stays realised below the rows, so that "last row" read *“on by default”* twice running and the walk concluded it had reached the end of Settings after two swipes. The section was never missing; the walk gave up. It now fingerprints the **whole visible set**, which is what the layout guards already do for exactly this reason, and this was the last test still asking the cheaper question.
